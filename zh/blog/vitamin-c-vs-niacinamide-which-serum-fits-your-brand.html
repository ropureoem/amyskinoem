维生素 C 与烟酰胺：哪款精华适合你的品牌？

维生素 C 是提亮的故事；烟酰胺是温和、修护屏障的故事。大多数新品牌从烟酰胺起步，因为它适合更多肤质——品牌准备好之后，再把维生素 C 作为第二款精华加上。

两款怎么比？

维生素 C 精华烟酰胺精华
故事提亮、光泽温和提亮、毛孔护理
浓度10% / 15% 维生素 C修护屏障，适合大多数肤质
最适合先推？是，如果你的品牌讲光泽是，对大多数新品牌来说
起订量每 SKU 500–1,000 件每 SKU 500–1,000 件

应该先推出哪一款？

问一个问题：你的品牌用一句话介绍这款精华，会说什么？如果这句话讲的是光泽与提亮，选维生素 C 精华。如果讲的是温和、适合大多数顾客的日常护理，选烟酰胺精华。两款都可以推出——每款是一个 SKU，MOQ 500–1,000——但先推出故事更清晰的那一款。

可以把两者合到一个配方里吗？

这是定制配方的问题。告诉我们你想讲的故事和你要卖的宣称，工厂团队会确认组合方向是否符合你所在市场的规则。不管怎样，大货生产前你先确认样品——见打样是怎么做的。
