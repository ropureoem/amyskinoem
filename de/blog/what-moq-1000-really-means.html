Startseite / Einblicke Was MOQ 500–1,000 wirklich bedeutet

6 Nov 2026 · Amy Skin OEM Einblicke

Was bedeutet MOQ 500–1,000 wirklich?

MOQ 500-1,000 bedeutet 500-1,000 Einheiten einer SKU - eine Rezeptur in einer Packung für einen Markt. Es ist die kleinste Großbestellung für dieses eine Produkt. Die Muster sind vom MOQ getrennt und der Preis wird pro Bestellung angegeben, nicht festgelegt.

Was ist eine SKU?

Eine SKU ist ein Produkt, wie Ihr Kunde es kauft: eine Rezeptur, in einer Packungsgröße, mit einem Etikett, für einen Markt. Ein Vitamin-C-Serum in einer 30-ml-Tropfenflasche für die EU ist eine SKU. Das gleiche Serum in einer anderen Packung oder mit einem anderen Etikett für einen anderen Markt ist eine andere SKU - und benötigt eigene 500-1,000 Einheiten.

Kann ich 250 Einheiten von zwei Produkten bestellen, um 500 zu erreichen?

Nein. MOQ 500-1,000 gilt pro SKU, nicht pro Bestellung insgesamt. Zwei Produkte mit je 250 Einheiten sind zwei SKUs unterhalb von MOQ. Wenn Sie zwei Produkte wünschen, benötigt jedes 500-1,000 Einheiten. Beginnen Sie mit dem einen Produkt, für das Ihre Marke bekannt ist, und fügen Sie dann das zweite hinzu.

Was beinhaltet MOQ 500–1,000 nicht?

  • Proben: Proben werden vor der Massenproduktion gemacht, so dass Sie die Rezeptur genehmigen können - sie sind von den 500-1,000 Einheiten getrennt.
  • Festpreis: Der Preis hängt von Rezeptur, Packung und Menge ab, so dass er pro Bestellung angegeben wird.
  • Zertifizierung für Ihren Markt: Die Registrierung oder Benachrichtigung Ihres Marktes ist ein separater Schritt - siehe Marktzertifizierungen.

Wie sollte eine neue Marke beginnen?

Beginnen Sie mit einer SKU bei MOQ 500-1,000: ein Heldenprodukt, eine klare Geschichte, ein Markt. Genehmigen Sie die Probe, bestätigen Sie die Verpackung und starten Sie. Fügen Sie eine zweite SKU nur hinzu, wenn die erste verkauft wird - so wächst eine kleine Marke, ohne Lagerbestände zu halten, die sie nicht verkaufen kann.
